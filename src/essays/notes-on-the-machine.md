this file exists so the build has something to render. delete it, or keep
it around as a template -- the shape of a piece is all here.

there are no italics on this machine. you underline. write _like this_ in
markdown and it comes out underlined. there is no bold either. you hit the
same key twice and the letter comes out a little darker, **like this**.

when you type the wrong word you don't reach for the white-out. you go
back and ~~hit x over it~~ strike it and keep going. two hyphens make a
dash -- like that. quotes stay "straight". nothing gets smartened.

## a heading, if you need one

same size as everything else. underlined so it reads as a heading and not
as the next paragraph. you probably won't need many.

set draft: true at the top of a piece to keep it off the contents page
and out of the feed until it's ready.
